JavaScript on this site

Third-party JavaScript

The libraries below are hosted on this site. Sizes refer to the JavaScript files before transfer compression (1 KiB = 1,024 bytes); stylesheets, fonts, and search index data are not included.

Script Size Purpose
KaTeX (katex.min.js) 265.8 KiB Renders mathematical notation at build time; not loaded by your browser.
Pagefind UI (pagefind-ui.js) 117.2 KiB Provides the search box and results in the site search panel.
Pagefind (pagefind.js) 44.5 KiB Loads the search engine and index data to search the published pages.

KaTeX runs when the site is published, so mathematical expressions are already rendered in the pages you receive. Disabling JavaScript does not prevent you from reading formulas. Pages with mathematics still load KaTeX's stylesheet and fonts. The RSS feed uses native MathML; its display depends on your feed reader's support for MathML.

Pagefind is loaded when you open the search panel, with further search resources loaded as needed. If JavaScript is disabled, you can use the Kagi search form below instead. Keep site:yijialog.org in the field and add your search terms after it.

Enter text after site:yijialog.org to search.

Built-in JavaScript

These small scripts provide the site's navigation and reading tools. Without JavaScript, article text, notes, tables, and ordinary links remain available, but these interactive features will not work. Mathematical notation also remains readable.

Script Size Purpose
math-reading.js 7.5 KiB Controls content visibility, proof and example folding, and saved reading preferences.
nav.js 2.4 KiB Controls the mobile navigation menu and marks the current navigation link.
random-post.js 0.7 KiB Opens a randomly selected blog post from the homepage.
search.js 2.9 KiB Opens the search panel and loads Pagefind when needed.
tags.js 1.9 KiB Filters the post list by tag and keeps the selected tag in the URL.
theme.js 1.8 KiB Switches between light, dark, and system themes and remembers the selection.
toc.js 3.6 KiB Provides a floating table of contents and highlights the current section.

A small inline script also applies the saved theme before the page is displayed, helping to avoid a flash of the wrong theme.
