ZF 1–3

Background

So far, we have used sets to construct number systems and prove their properties. We now turn to the rules that justify these constructions. Which collections exist as sets, and which operations on sets are permitted? Zermelo–Fraenkel set theory, abbreviated ZF, gives an axiomatic framework for answering these questions. Adding the axiom of choice gives ZFC.

Remark 1 — Intension and extension

The intension of a description is the condition or meaning used to specify its objects; its extension is the collection of objects satisfying that condition. Different descriptions can have the same extension. For example, among integers, being divisible by 222 and having remainder 000 on division by 222 describe the same collection.

Sets are treated extensionally: what matters for equality is which elements they have, rather than how those elements were described. The distinction has historical significance in the development of logic and set theory, and it motivates the axiom of extensionality that we will introduce below.

Remark 2 — A universal set and unrestricted comprehension

Two initially natural proposals are the existence of a universal set UUU containing every set, ∃U ∀x (x∈U), \exists U\,\forall x\,(x\in U), ∃U∀x(x∈U), and unrestricted comprehension: every condition φ(x)\varphi(x)φ(x) determines a set consisting of exactly the sets satisfying it, ∃A ∀x (x∈A  ⟺  φ(x)). \exists A\,\forall x\,(x\in A\iff\varphi(x)). ∃A∀x(x∈A⟺φ(x)). In the second expression, AAA must not occur freely in φ\varphiφ, and parameters may be allowed in the condition. This is a proposed axiom schema, with one instance for each formula, rather than a single axiom quantifying over formulas.

Taking φ(x)\varphi(x)φ(x) to be x=xx=xx=x would already produce a universal set. These proposals help explain the motivation for axiomatic set theory, but unrestricted comprehension is inconsistent. ZF instead restricts set formation; a condition alone does not guarantee that its extension is a set.

Remark 3 — Russell's paradox

Unrestricted comprehension would give a set R={x∣x∉x}. R=\{x\mid x\notin x\}. R={x∣x∈/x}. Asking whether RRR belongs to itself gives R∈R  ⟺  R∉R, R\in R\iff R\notin R, R∈R⟺R∈/R, a contradiction. If RRR belongs to itself, its defining condition excludes it; if it does not, the same condition includes it.

The difficulty is the assumption that this condition defines a set. ZF will permit us to select elements satisfying a condition from an already existing set, without asserting that every condition gives a set of all its instances. In particular, a universal set together with this restricted selection principle would still yield the same contradiction.

Definition 4 — Classes

A class described by a formula φ(x)\varphi(x)φ(x) is the collection of all sets satisfying that formula, written C={x∣φ(x)}. C=\{x\mid\varphi(x)\}. C={x∣φ(x)}. The notation x∈Cx\in Cx∈C abbreviates φ(x)\varphi(x)φ(x). Such a class is a set if there is a set aaa such that ∀x (x∈a  ⟺  φ(x)). \forall x\,(x\in a\iff\varphi(x)). ∀x(x∈a⟺φ(x)). Otherwise it is called a proper class.

We use classes as convenient descriptions in our discussion of ZF. They are not additional objects over which the variables of ZF range. For example, the universal class V={x∣x=x}V=\{x\mid x=x\}V={x∣x=x} describes all sets, while Russell's condition describes a proper class rather than a contradictory set.

Remark 5 — The relationship between sets and classes

A class is the broader concept in our terminology: every set determines a class, but a class need not be a set. A proper class is precisely a class that is not a set. Thus a class is either a set or a proper class; these two possibilities are mutually exclusive.

This is a relationship between concepts, not a claim that there is a set whose elements are all classes. In ZF, variables range over sets, while class notation is shorthand for formulas. Calling a class a set says that its defining condition is represented by an object in this universe of sets.

In the following sections, we will express the axioms in first-order logic, using logical symbols such as ∀\forall∀, ∃\exists∃, ¬\neg¬, ∧\land∧, and   ⟹  \implies⟹, together with equality === and membership ∈\in∈. All variables range over sets. Equality is ordinary logical equality; membership is the sole nonlogical relation symbol. Set operations and class notation are abbreviations whose meanings must be supplied by definitions and axioms.

Before imposing the axioms, we assume no special properties of ∈\in∈: it is a binary relation, and it is not automatically reflexive, symmetric, or transitive. We write x∉yx\notin yx∈/y for ¬(x∈y)\neg(x\in y)¬(x∈y). A chain x∈y∈zx\in y\in zx∈y∈z abbreviates x∈y∧y∈zx\in y\land y\in zx∈y∧y∈z and does not by itself imply x∈zx\in zx∈z.

Extensionality, empty set, and pairs

Axiom 6 — ZF1 — Extensionality

Any two sets having exactly the same elements are equal. ∀a ∀b (∀x (x∈a  ⟺  x∈b)  ⟹  a=b). \forall a\,\forall b\,\bigl(\forall x\,(x\in a\iff x\in b)\implies a=b\bigr). ∀a∀b(∀x(x∈a⟺x∈b)⟹a=b).

The converse follows from the logical rules for equality. Thus extensionality makes the members of a set determine it completely.

Axiom 7 — ZF2 — Empty set

There exists a set having no elements. ∃e ∀x ¬(x∈e). \exists e\,\forall x\,\neg(x\in e). ∃e∀x¬(x∈e).

Axiom 8 — ZF3 — Pairs

For any two sets, there exists a set whose elements are exactly those two sets. ∀a ∀b ∃p ∀x (x∈p  ⟺  (x=a∨x=b)). \forall a\,\forall b\,\exists p\,\forall x\, \bigl(x\in p\iff(x=a\lor x=b)\bigr). ∀a∀b∃p∀x(x∈p⟺(x=a∨x=b)). The two given sets are not required to be distinct.

Corollary 9 — Uniqueness of the empty set and pairs

The set in ZF2 is unique. For each fixed choice of a,ba,ba,b, the set in ZF3 is also unique.

Proof.

Any two sets with no elements have exactly the same elements, so ZF1 makes them equal. Likewise, two sets whose elements are exactly aaa and bbb have the same elements and are equal by ZF1.

□
Theorem 10 — Existence of singleton sets

For every set aaa, there exists a unique set sss whose only element is aaa: ∀a ∃s ∀x (x∈s  ⟺  x=a). \forall a\,\exists s\,\forall x\,(x\in s\iff x=a). ∀a∃s∀x(x∈s⟺x=a).

Proof.

Apply ZF3 with both inputs equal to aaa. It gives a set sss with x∈sx\in sx∈s if and only if x=a∨x=ax=a\lor x=ax=a∨x=a, which is equivalent to x=ax=ax=a. Uniqueness follows from ZF1.

□
Definition 11 — Empty set, unordered pairs, and singletons

The empty set, denoted by ∅\varnothing∅ or {}\{\}{}, is the unique set with no elements. The unordered pair of aaa and bbb is {a,b}, \{a,b\}, {a,b}, the unique set whose elements are exactly aaa and bbb. The singleton of aaa is {a}\{a\}{a}, the unique set whose only element is aaa.

ZF2 guarantees the empty set, ZF3 guarantees unordered pairs, and Theorem 10 guarantees singletons. Extensionality guarantees uniqueness in each case, so these notations specify particular sets. In particular, {a,b}={b,a}\{a,b\}=\{b,a\}{a,b}={b,a} and {a,a}={a}\{a,a\}=\{a\}{a,a}={a}.

Ordered pairs

Definition 12 — Ordered pairs

For sets x,yx,yx,y, define their ordered pair by ⟨x,y⟩={{x},{x,y}}. \langle x,y\rangle=\{\{x\},\{x,y\}\}. ⟨x,y⟩={{x},{x,y}}. This is the Kuratowski definition.

The singleton {x}\{x\}{x} and the unordered pair {x,y}\{x,y\}{x,y} exist uniquely by the preceding results. Applying ZF3 once more gives the outer pair, whose uniqueness follows from ZF1. Thus the definition determines a unique set for every choice of x,yx,yx,y, using only the first three axioms.

Theorem 13 — Equality of ordered pairs

For all sets x,y,u,vx,y,u,vx,y,u,v, ⟨x,y⟩=⟨u,v⟩  ⟺  x=u and y=v. \langle x,y\rangle=\langle u,v\rangle \iff x=u\text{ and }y=v. ⟨x,y⟩=⟨u,v⟩⟺x=u and y=v.

Proof.

If x=ux=ux=u and y=vy=vy=v, the pairs are equal by substitution. Conversely, suppose {{x},{x,y}}={{u},{u,v}}. \{\{x\},\{x,y\}\}=\{\{u\},\{u,v\}\}. {{x},{x,y}}={{u},{u,v}}. Since {x}\{x\}{x} belongs to the right-hand side, it equals either {u}\{u\}{u} or {u,v}\{u,v\}{u,v}. In either case u∈{x}u\in\{x\}u∈{x}, so u=xu=xu=x.

Substituting this gives {{x},{x,y}}={{x},{x,v}}. \{\{x\},\{x,y\}\}=\{\{x\},\{x,v\}\}. {{x},{x,y}}={{x},{x,v}}. If y=xy=xy=x, the left-hand side is the singleton {{x}}\{\{x\}\}{{x}}. Hence {x,v}={x}\{x,v\}=\{x\}{x,v}={x} and v=x=yv=x=yv=x=y.

If y≠xy\ne xy=x, then {x,y}≠{x}\{x,y\}\ne\{x\}{x,y}={x}. Its membership in the right-hand side therefore forces {x,y}={x,v}\{x,y\}=\{x,v\}{x,y}={x,v}. Since y≠xy\ne xy=x, we must have y=vy=vy=v. This proves both coordinate equalities.

Remark 14 — Why the encoding matters

The tempting encoding P(x,y)={x,{y}}P(x,y)=\{x,\{y\}\}P(x,y)={x,{y}} loses the order of some inputs. For distinct sets a,ba,ba,b, P({a},b)={{a},{b}}=P({b},a), P(\{a\},b)=\{\{a\},\{b\}\}=P(\{b\},a), P({a},b)={{a},{b}}=P({b},a), although the input pairs are different. Thus equality of outputs does not recover the coordinates.

The alternative Q(x,y)={x,{x,y}}Q(x,y)=\{x,\{x,y\}\}Q(x,y)={x,{x,y}} does work in ZF, but its verification uses the axiom of foundation, introduced later. Foundation rules out x={x,y}x=\{x,y\}x={x,y} and also rules out a two-way membership cycle. Therefore, if two such encodings are equal, the elements xxx and uuu cannot be matched in the swapped order: that would give x={u,v}x=\{u,v\}x={u,v} and u={x,y}u=\{x,y\}u={x,y}, hence u∈x∈uu\in x\in uu∈x∈u. The remaining matching gives x=ux=ux=u and then y=vy=vy=v.

We use the Kuratowski encoding because its coordinate property already follows from ZF1–3, without needing foundation.

Definition 15 — Tuples and finite ordered lists

For a fixed positive length nnn, define an ordered $n$-tuple recursively by ⟨x1⟩=x1,⟨x1,…,xn,xn+1⟩=⟨⟨x1,…,xn⟩,xn+1⟩. \langle x_1\rangle=x_1,\qquad \langle x_1,\ldots,x_n,x_{n+1}\rangle =\langle\langle x_1,\ldots,x_n\rangle,x_{n+1}\rangle. ⟨x1​⟩=x1​,⟨x1​,…,xn​,xn+1​⟩=⟨⟨x1​,…,xn​⟩,xn+1​⟩. In particular, the case n=2n=2n=2 is the ordered pair already defined.

When the length must also be recorded, define a finite ordered list by list⁡(x1,…,xn)=⟨n,⟨x1,…,xn⟩⟩(n≥1), \operatorname{list}(x_1,\ldots,x_n) =\langle n,\langle x_1,\ldots,x_n\rangle\rangle \quad(n\geq1), list(x1​,…,xn​)=⟨n,⟨x1​,…,xn​⟩⟩(n≥1), and define the empty list to be ⟨0,∅⟩\langle0,\varnothing\rangle⟨0,∅⟩.

For any fixed finite length, repeated applications of the ordered-pair construction give existence and uniqueness of the tuple. The list encoding additionally records the length; here we use the natural-number notation developed in the preceding chapter, with its set-theoretic existence supplied by the axioms discussed later.

Proposition 16 — Equality of tuples and lists

For a fixed positive length nnn, ⟨x1,…,xn⟩=⟨y1,…,yn⟩  ⟺  xi=yi for every 1≤i≤n. \langle x_1,\ldots,x_n\rangle=\langle y_1,\ldots,y_n\rangle \iff x_i=y_i\text{ for every }1\leq i\leq n. ⟨x1​,…,xn​⟩=⟨y1​,…,yn​⟩⟺xi​=yi​ for every 1≤i≤n. Two finite ordered lists are equal if and only if their lengths are equal and their corresponding entries are equal.

Proof.

For tuples, induct on nnn. The assertion for n=1n=1n=1 is immediate. At the successor step, Theorem 13 gives equality of the final coordinates and equality of the two shorter tuples. The induction hypothesis identifies all their coordinates. The reverse implication follows by substitution.

For lists, the outer ordered pair first recovers the length. If that length is positive, the tuple result recovers all entries. At length zero there is only the specified empty list.

□
Remark 17 — Keeping all the information in an encoding

There are other possible encodings, but equality of outputs must allow us to recover all the intended input data.

  1. Right-nested pairs. For fixed length, using ⟨x1,⟨x2,x3⟩⟩\langle x_1,\langle x_2,x_3\rangle\rangle⟨x1​,⟨x2​,x3​⟩⟩ for a triple also works: applying the ordered-pair theorem repeatedly recovers each coordinate. It differs from our left-nested convention, so the convention must be specified.
  2. Indexed functions. A list of length nnn can be represented by a function with domain nnn, sending each position to its entry. The domain records the length, and the function values record the entries. We will justify the relevant set constructions using later axioms.
  3. Unordered sets of entries. Replacing a list by {x1,…,xn}\{x_1,\ldots,x_n\}{x1​,…,xn​} does not work. It forgets order and repetitions: the lists with entries a,ba,ba,b and b,ab,ab,a give the same set, as do the lists with entries aaa and a,aa,aa,a.
  4. Nesting without a length tag. Our tuple encoding works for each fixed length, but does not distinguish all lengths. If z=⟨a,b⟩z=\langle a,b\ranglez=⟨a,b⟩, the one-tuple ⟨z⟩\langle z\rangle⟨z⟩ and the two-tuple ⟨a,b⟩\langle a,b\rangle⟨a,b⟩ are the same set. The outer length tag in the list definition prevents this loss of information.

The particular representing sets are a convention. Recovering positions, entries, and, for lists, length is the essential requirement.
