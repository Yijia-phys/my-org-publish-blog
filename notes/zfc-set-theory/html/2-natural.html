Peano axioms

We begin by describing the natural numbers through a distinguished initial element and an operation that moves from each element to the next.

Von Neumann's definition

Definition 7 — The successor of a set

For any set xxx, define its successor by x+=x∪{x}. x^+=x\cup\{x\}. x+=x∪{x}.

This operation retains every element of xxx and also includes xxx itself as an element.

Definition 8 — Inductive sets

A set III is inductive if

  1. ∅∈I\varnothing\in I∅∈I;
  2. for every x∈Ix\in Ix∈I, we have x+∈Ix^+\in Ix+∈I.

An inductive set contains the starting point and is closed under taking successors. We will use the axiom of infinity, introduced later, to guarantee that at least one such set exists.

Lemma 9 — Intersections of inductive sets

If III and JJJ are inductive sets, then I∩JI\cap JI∩J is inductive.

Proof.

Both sets contain ∅\varnothing∅, so ∅∈I∩J\varnothing\in I\cap J∅∈I∩J. If x∈I∩Jx\in I\cap Jx∈I∩J, then x∈Ix\in Ix∈I and x∈Jx\in Jx∈J. Their inductiveness gives x+∈Ix^+\in Ix+∈I and x+∈Jx^+\in Jx+∈J, hence x+∈I∩Jx^+\in I\cap Jx+∈I∩J.

□

The same argument works for the intersection of any nonempty family of inductive sets: the empty set belongs to every member, and taking a successor preserves membership in every member.

Definition 10 — The set of natural numbers

The set of natural numbers, denoted by N\mathbb{N}N, is the intersection of all inductive sets: x∈N  ⟺  x belongs to every inductive set. x\in\mathbb{N}\iff x\text{ belongs to every inductive set}. x∈N⟺x belongs to every inductive set. More precisely, fix an inductive set III and define N={x∈I∣x belongs to every inductive set}. \mathbb{N}=\{x\in I\mid x\text{ belongs to every inductive set}\}. N={x∈I∣x belongs to every inductive set}. This definition does not depend on the choice of III.

The restricted description makes N\mathbb{N}N a set without requiring a set of all inductive sets. By the intersection argument in Lemma 9, N\mathbb{N}N is itself inductive. It is therefore the least inductive set: it is contained in every inductive set.
