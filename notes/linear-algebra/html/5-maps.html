Linear maps

Definition 1 — Linear map

Let VVV and WWW be vector spaces over the same field KKK. A function T:V→WT:V\to WT:V→W is K-linear if, for all u,v∈Vu,v\in Vu,v∈V and a∈Ka\in Ka∈K, T(u+v)=T(u)+T(v),T(av)=aT(v). T(u+v)=T(u)+T(v),\qquad T(av)=aT(v). T(u+v)=T(u)+T(v),T(av)=aT(v). Equivalently, for all a,b∈Ka,b\in Ka,b∈K, T(au+bv)=aT(u)+bT(v). T(au+bv)=aT(u)+bT(v). T(au+bv)=aT(u)+bT(v). Such a function is called a linear map or linear transformation. The field specifies which scalars these identities must hold for.

The map T:R2→R3,T(x1,x2)=(x1+2x2, x1−x2, 3x2) T:\mathbb{R}^2\to\mathbb{R}^3,\qquad T(x_1,x_2)=(x_1+2x_2,\ x_1-x_2,\ 3x_2) T:R2→R3,T(x1​,x2​)=(x1​+2x2​, x1​−x2​, 3x2​) is R\mathbb{R}R-linear. Each output coordinate is a linear combination of the input coordinates, so substitution gives T(au+bv)=aT(u)+bT(v)T(au+bv)=aT(u)+bT(v)T(au+bv)=aT(u)+bT(v).

Example 3 — Differentiation

The map D:P2(R)→P1(R),D(a+bt+ct2)=b+2ct D:P_2(\mathbb{R})\to P_1(\mathbb{R}),\qquad D(a+bt+ct^2)=b+2ct D:P2​(R)→P1​(R),D(a+bt+ct2)=b+2ct is R\mathbb{R}R-linear. Corollary 17 — The linear pigeonhole principle

For a linear map T:V→WT:V\to WT:V→W:

  1. If dim⁡KV>dim⁡KW\dim_K V>\dim_K WdimK​V>dimK​W, then TTT cannot be injective.
  2. If dim⁡KV<dim⁡KW\dim_K V<\dim_K WdimK​V<dimK​W, then TTT cannot be surjective.
  3. If dim⁡KV=dim⁡KW\dim_K V=\dim_K WdimK​V=dimK​W, then injectivity, surjectivity, and bijectivity of TTT are equivalent.
Proof.

Choose a basis BBB of VVV, with n=dim⁡KVn=\dim_K Vn=dimK​V elements.

If TTT is injective, the image T[B]T[B]T[B] is independent and has nnn elements, so n≤dim⁡KWn\leq\dim_K Wn≤dimK​W. This proves the first assertion.

If TTT is surjective, T[B]T[B]T[B] spans WWW and has at most nnn elements. A spanning set must have at least dim⁡KW\dim_K WdimK​W elements, proving the second assertion.

Now suppose both dimensions equal nnn. If TTT is injective, T[B]T[B]T[B] is an independent set of nnn vectors in WWW, hence a basis. Thus TTT is surjective.

Conversely, if TTT is surjective, T[B]T[B]T[B] spans WWW. It has at most nnn elements, and the spanning-set bound forces it to have exactly nnn. It is therefore a basis. Writing B={b1,…,bn}B=\{b_1,\ldots,b_n\}B={b1​,…,bn​}, a vector v=∑iaibiv=\sum_i a_ib_iv=∑i​ai​bi​ in the kernel satisfies ∑iaiT(bi)=0W\sum_i a_iT(b_i)=0_W∑i​ai​T(bi​)=0W​. The images are distinct basis vectors, so every ai=0Ka_i=0_Kai​=0K​. Thus the kernel is zero and TTT is injective.

□
Remark 18 — Why dimension gives a pigeonhole principle

Dimension is the cardinality of a basis. An independent set has at most that many elements, while a spanning set has at least that many. Injective linear maps preserve independence, and surjective linear maps send spanning sets to spanning sets. These facts give the three dimension restrictions above.

Isomorphisms

Definition 20 — Isomorphism

Let VVV and WWW be vector spaces over the same field KKK. An isomorphism T:V→WT:V\to WT:V→W is a bijective KKK-linear map. If such a map exists, the spaces are isomorphic over K, written V≅KWV\cong_K WV≅K​W.

Given ordered bases A=(v1,…,vn)A=(v_1,\ldots,v_n)A=(v1​,…,vn​) of VVV and B=(w1,…,wn)B=(w_1,\ldots,w_n)B=(w1​,…,wn​) of WWW, define the corresponding map TB←A:V→W,TB←A(∑i=1naivi)=∑i=1naiwi. T_{B\leftarrow A}:V\to W,\qquad T_{B\leftarrow A}\left(\sum_{i=1}^n a_iv_i\right) =\sum_{i=1}^n a_iw_i. TB←A​:V→W,TB←A​(i=1∑n​ai​vi​)=i=1∑n​ai​wi​. It sends viv_ivi​ to wiw_iwi​, keeping the coefficients and replacing the basis vectors. The arrow points from the source basis AAA to the target basis BBB.

Proposition 21 — Isomorphism and dimension

For finite-dimensional vector spaces V,WV,WV,W over KKK, V≅KW  ⟺  dim⁡KV=dim⁡KW. V\cong_K W\iff\dim_K V=\dim_K W. V≅K​W⟺dimK​V=dimK​W.

Proof.

If T:V→WT:V\to WT:V→W is an isomorphism, it sends a basis of VVV to a basis of WWW: injectivity preserves independence, and surjectivity sends a spanning set to a spanning set. The image basis has the same number of elements, so the dimensions agree.

Conversely, suppose both dimensions equal nnn. Choose ordered bases A=(v1,…,vn)A=(v_1,\ldots,v_n)A=(v1​,…,vn​) and B=(w1,…,wn)B=(w_1,\ldots,w_n)B=(w1​,…,wn​). Every vector has unique basis coefficients, so TB←AT_{B\leftarrow A}TB←A​ is well-defined. Adding coefficient lists or multiplying them by a scalar shows that it is linear.

The map TA←BT_{A\leftarrow B}TA←B​ reverses the replacement of basis vectors, giving TA←B∘TB←A=id⁡V,TB←A∘TA←B=id⁡W. T_{A\leftarrow B}\circ T_{B\leftarrow A}=\operatorname{id}_V,\qquad T_{B\leftarrow A}\circ T_{A\leftarrow B}=\operatorname{id}_W. TA←B​∘TB←A​=idV​,TB←A​∘TA←B​=idW​. Thus TB←AT_{B\leftarrow A}TB←A​ is bijective and hence an isomorphism.

□
Remark 22 — Bases and the axiom of choice

The construction depends on the chosen ordered bases: equal dimension gives the existence of an isomorphism, but does not specify a unique one.

Our finite-dimensional argument needs only finitely many choices. In full generality, the assertion that every vector space has a basis is equivalent to the axiom of choice. With that assumption, the same construction works for arbitrary bases: choose a bijection between the bases and extend it linearly. Isomorphic spaces then have the same basis cardinality, even when it is infinite.

Theorem 23 — Invertible linear maps and their inverses
