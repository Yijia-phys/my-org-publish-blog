Equations

Definition 1 — Linear equations and systems

A linear equation in the real unknowns x1,…,xnx_1,\ldots,x_nx1​,…,xn​ is an equation of the form a1x1+⋯+anxn=b, a_1x_1+\cdots+a_nx_n=b, a1​x1​+⋯+an​xn​=b, where the coefficients a1,…,ana_1,\ldots,a_na1​,…,an​ and the right-hand side bbb are fixed real numbers.

A system of linear equations is a collection of such equations in the same unknowns: a11x1+⋯+a1nxn=b1,⋮am1x1+⋯+amnxn=bm.\begin{aligned} a_{11}x_1+\cdots+a_{1n}x_n&=b_1,\\ &\vdots\\ a_{m1}x_1+\cdots+a_{mn}x_n&=b_m. \end{aligned}a11​x1​+⋯+a1n​xn​am1​x1​+⋯+amn​xn​​=b1​,⋮=bm​.​ A solution is a vector (x1,…,xn)∈Rn(x_1,\ldots,x_n)\in\mathbb{R}^n(x1​,…,xn​)∈Rn satisfying every equation in the system.

Example 2 — One linear equation and two nonlinear equations

In the unknowns x1,x2x_1,x_2x1​,x2​:

  1. 3x1−2x2=53x_1-2x_2=53x1​−2x2​=5 is linear: both coefficients and the right-hand side are constants.
  2. x1x2=1x_1x_2=1x1​x2​=1 is not linear, because it contains a product of unknowns.
  3. x12+x2=0x_1^2+x_2=0x12​+x2​=0 is not linear, because it contains the square of an unknown.

Concepts

A matrix records the coefficients of a system in a rectangular array. Throughout this chapter, matrix dimensions are positive integers.

Remark 12 — When can matrices be multiplied?

The number of columns of the left matrix must equal the number of rows of the right matrix: (m×n)(n×p)⟶m×p. (m\times n)(n\times p)\longrightarrow m\times p. (m×n)(n×p)⟶m×p. The inner dimensions match; the outer dimensions give the size of the answer. Equivalently, BBB takes a vector with ppp coordinates to one with nnn coordinates, which is the input size required by AAA.

Matrix sums in the next proposition are taken entry by entry; see Definition 18 below.

Definition 27 — Row echelon form and reduced row echelon form

A matrix is in row echelon form (REF) if:

  1. All zero rows occur below all nonzero rows.
  2. The first nonzero entry in each nonzero row is 111, called its leading 1 or pivot.
  3. Each leading 111 lies strictly to the right of the leading 111 in the row above it.
  4. All entries below a leading 111 are zero.

It is in reduced row echelon form (RREF) if, in addition, each leading 111 is the only nonzero entry in its column. A column containing a leading 111 is called a pivot column.

In these notes, REF requires a leading 1, not merely a nonzero leading entry. Some books use the latter convention. RREF also requires zeros above each leading 111; other entries in its row need not be zero.

Example 28 — Three examples
  1. The matrix (12−1013000)\begin{pmatrix}1&2&-1\\0&1&3\\0&0&0\end{pmatrix} ​100​210​−130​​ is in REF, with leading $1$s in columns 111 and 222. It is not in RREF, because the entry above the second leading 111 is 222.
  2. The matrix (120−300140000)\begin{pmatrix}1&2&0&-3\\0&0&1&4\\0&0&0&0\end{pmatrix} ​100​200​010​−340​​ is in RREF. Its leading $1$s lie in columns 111 and 333, and all other entries in those columns are zero. The entries in columns 222 and 444 are allowed to be nonzero.
  3. The matrix (2101)\begin{pmatrix}2&1\\0&1\end{pmatrix} (20​11​) is not in REF under our convention: its first row starts with 222. Dividing that row by 222 gives a leading 111 and puts the matrix in REF.
Theorem 29 — Gauss–Jordan elimination

Every real matrix can be transformed into RREF by a finite sequence of elementary row operations. Applied to an augmented matrix, this procedure preserves the solution set.

Proof.

Starting with the first row, find the leftmost column containing a nonzero entry among the rows still to be processed. Move a row with such an entry to the top of those rows. Divide it by its leading entry to make a leading 111, then subtract multiples of this row to make every entry below that 111 zero.

Repeat on the remaining rows, using columns to the right of the previous pivot. Those rows are already zero in earlier pivot columns, so these operations preserve the previous steps. If the remaining rows are all zero, stop. Each step uses a new row and a new pivot column, so only finitely many steps are possible. This gives REF.

Now work upward from the last nonzero row. Subtract multiples of each pivot row from the rows above it to clear its pivot column. Since a pivot row is zero to the left of its leading 111, and later pivot columns have already been cleared, this preserves the other pivot columns. The result is RREF. Every step is an ERO, so Theorem 26 applies to an augmented matrix.
