Remark 4 — Characteristic

The characteristic of a field KKK, written char⁡K\operatorname{char}KcharK, is the smallest positive integer ppp for which the sum of ppp copies of 1K1_K1K​ is 0K0_K0K​. If no such integer exists, the characteristic is 000.

Remark 12 — What can be a vector?

A vector is an element of a vector space; it need not be an arrow or a tuple. Polynomials and matrices already give other examples.

More generally, any set SSS can supply labels for formal vectors. Form finite formal sums a1[s1]+⋯+ar[sr],ai∈K, si∈S, a_1[s_1]+\cdots+a_r[s_r],\qquad a_i\in K,\ s_i\in S, a1​[s1​]+⋯+ar​[sr​],ai​∈K, si​∈S, combining coefficients of identical labels and omitting zero coefficients. Add such sums by adding their coefficients and multiply them by scalars coefficientwise. These sums form a vector space over KKK, with the empty sum as zero, and each s∈Ss\in Ss∈S corresponds to the vector [s][s][s].

This realizes the elements of any set as vectors in a larger construction. It does not say that every set itself admits a vector-space structure without adding these formal sums.

Subspaces

Definition 13 — K-linear subspace

Let VVV be a vector space over KKK. A subset W⊆VW\subseteq VW⊆V is a K-linear subspace of VVV if it is itself a vector space over KKK under the addition and scalar multiplication inherited from VVV.

Both the operations and the scalar field are inherited: scalar multiplication must work for every scalar in KKK.

Theorem 14 — The subspace test

A subset WWW of a vector space VVV over KKK is a $K$-linear subspace if and only if:

  1. WWW is nonempty.
  2. For all u,v∈Wu,v\in Wu,v∈W, we have u+v∈Wu+v\in Wu+v∈W.

Proof.

If WWW is a vector space under the inherited operations, it is nonempty and closed under those operations, so the three conditions hold.

Conversely, suppose the conditions hold. Choose w∈Ww\in Ww∈W. Scalar closure gives 0Kw=0V∈W0_Kw=0_V\in W0K​w=0V​∈W. For every v∈Wv\in Wv∈W, it also gives (−1K)v=−v∈W(-1_K)v=-v\in W(−1K​)v=−v∈W. Associativity, commutativity, and all scalar multiplication axioms hold because they already hold in VVV. Thus WWW is a vector space over KKK with the inherited operations.

Definition 27 — Linear dependence and independence

Let v1,…,vmv_1,\ldots,v_mv1​,…,vm​ be vectors in a vector space over KKK. They are linearly independent over K (LI) if a1v1+⋯+amvm=0V,a1,…,am∈K, a_1v_1+\cdots+a_mv_m=0_V,\qquad a_1,\ldots,a_m\in K, a1​v1​+⋯+am​vm​=0V​,a1​,…,am​∈K, implies a1=⋯=am=0Ka_1=\cdots=a_m=0_Ka1​=⋯=am​=0K​.

A subset SSS is linearly independent over KKK if every finite family of distinct elements of SSS is linearly independent; otherwise it is linearly dependent. The empty family is linearly independent, since it has no nontrivial linear relation.

A family is linearly dependent if it contains the zero vector, contains the same vector twice, or contains two vectors one of which is a scalar multiple of the other. If v1,…,vm∈Knv_1,\ldots,v_m\in K^nv1​,…,vm​∈Kn are linearly independent over KKK, then m≤nm\leq nm≤n. Consequently, every linearly independent subset of KnK^nKn has at most nnn elements.

Proof.

If m>nm>nm>n, there are more columns than possible pivots, so Aa=0Aa=0Aa=0 has a nonpivot unknown. Assign one such unknown the value 1K1_K1K​ and all other nonpivot unknowns zero, then solve for the pivot unknowns. This gives a nonzero solution, contradicting Theorem 29. Hence m≤nm\leq nm≤n.

If an independent subset had more than nnn elements, choosing n+1n+1n+1 distinct members would contradict this bound.

Theorem 39 — Extending an independent set to a basis

Suppose VVV over KKK has a finite spanning set TTT. Every linearly independent subset S⊆VS\subseteq VS⊆V can be extended to a finite basis of VVV. Moreover, ∣S∣≤∣T∣|S|\leq|T|∣S∣≤∣T∣.

Proof.

Now start with SSS and consider each vector of TTT in turn. Add it if it is outside the span of the vectors already selected. This preserves independence: a relation with a nonzero coefficient on the new vector would express it in the old span; if that coefficient is zero, independence of the old set makes all coefficients zero.

After finitely many steps, the selected set is independent and its span contains every element of TTT. It therefore spans VVV, so it is a finite basis containing SSS.

Proposition 41 — Dimension of a subspace

If UUU is a $K$-linear subspace of VVV, then UUU is finite-dimensional and dim⁡KU≤dim⁡KV. \dim_K U\leq\dim_K V. dimK​U≤dimK​V.
