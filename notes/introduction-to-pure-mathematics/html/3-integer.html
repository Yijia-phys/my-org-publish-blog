The well-ordering principle

An ordering lets us compare elements, but it does not by itself guarantee a smallest or largest element of a set. We first make these notions precise.

Definition 1 — Maximum and minimum elements

Let A⊆RA\subseteq\mathbb{R}A⊆R.

  1. A maximum element of AAA is an element M∈AM\in AM∈A such that every element of AAA is at most MMM: M∈Aand(∀x∈A) (x≤M). M\in A\quad\text{and}\quad(\forall x\in A)\,(x\leq M). M∈Aand(∀x∈A)(x≤M). When it exists, we write M=max⁡AM=\max AM=maxA.
  2. A minimum element of AAA is an element m∈Am\in Am∈A such that every element of AAA is at least mmm: m∈Aand(∀x∈A) (m≤x). m\in A\quad\text{and}\quad(\forall x\in A)\,(m\leq x). m∈Aand(∀x∈A)(m≤x). When it exists, we write m=min⁡Am=\min Am=minA.

A maximum or minimum must belong to the set itself. Neither need exist: the interval (0,1)(0,1)(0,1) has neither a maximum nor a minimum. The set Z≥0\mathbb{Z}_{\geq0}Z≥0​ has minimum 000 but no maximum. Whenever a maximum or minimum exists, it is unique: two candidates must each be at most the other, so they are equal.

Theorem 2 — The nonnegative integers are linearly ordered

The usual relation ≤\leq≤ linearly orders Z≥0\mathbb{Z}_{\geq0}Z≥0​. More explicitly, for all a,b,c∈Z≥0a,b,c\in\mathbb{Z}_{\geq0}a,b,c∈Z≥0​:

  1. a≤aa\leq aa≤a.
  2. If a≤ba\leq ba≤b and b≤ab\leq ab≤a, then a=ba=ba=b.
  3. If a≤ba\leq ba≤b and b≤cb\leq cb≤c, then a≤ca\leq ca≤c.
  4. Either a≤ba\leq ba≤b or b≤ab\leq ab≤a.
Proof.

These properties hold for the usual order on R\mathbb{R}R, and hence hold when we restrict it to the subset Z≥0\mathbb{Z}_{\geq0}Z≥0​.

The nonnegative integers have a stronger property: every nonempty subset has a first element. This is the well-ordering principle, abbreviated WOP.

The Euclidean algorithm

The Euclidean algorithm computes a gcd by repeated division, without listing all the divisors. Given integers a,ba,ba,b, first replace them by their absolute values and, if necessary, interchange them so that a≥b≥0a\geq b\geq0a≥b≥0. These changes do not affect the gcd.

If b=0b=0b=0, the answer is aaa, including the case a=b=0a=b=0a=b=0. Otherwise, proceed as follows:

  1. Divide aaa by bbb to obtain a=bq+ra=bq+ra=bq+r with 0≤r<b0\leq r<b0≤r<b.
  2. If r=0r=0r=0, stop: the gcd is bbb.
  3. If r>0r>0r>0, replace the pair (a,b)(a,b)(a,b) by (b,r)(b,r)(b,r) and repeat.

In words, divide the previous divisor by the previous remainder, continuing until the remainder is zero. The answer is the last nonzero remainder, or the initial divisor if the very first remainder is zero.

Theorem 16 — Termination and correctness of the Euclidean algorithm

The Euclidean algorithm terminates after finitely many divisions and returns gcd⁡(a,b)\gcd(a,b)gcd(a,b).

Proof.

First consider termination. At every division, a nonzero remainder is a positive integer strictly smaller than the divisor. Thus, if the algorithm never stopped, its successive divisors would form a strictly decreasing sequence of positive integers. By WOP, the set of these divisors would have a minimum element. But the next divisor would be smaller still, a contradiction. Therefore a zero remainder must eventually occur.

For correctness, at each step we have a=bq+ra=bq+ra=bq+r. By the adding-a-multiple property in Theorem 11, gcd⁡(a,b)=gcd⁡(b,a)=gcd⁡(b,a−bq)=gcd⁡(b,r). \gcd(a,b)=\gcd(b,a)=\gcd(b,a-bq)=\gcd(b,r). gcd(a,b)=gcd(b,a)=gcd(b,a−bq)=gcd(b,r). Thus replacing (a,b)(a,b)(a,b) by (b,r)(b,r)(b,r) preserves the gcd. At termination, the final division has the form s=dq+0s=dq+0s=dq+0, with d>0d>0d>0. The gcd of this final pair is gcd⁡(s,d)=d\gcd(s,d)=dgcd(s,d)=d, so ddd is also the gcd of the original pair. This is the last nonzero remainder, or the initial divisor if the first division is exact. The cases with an initial zero divisor were already handled above.

The positive-divisor description is often the first way we recognise a prime. We use the product property as our definition because it is the property we need when working with factorizations: if a prime divides a finite product, repeated application shows that it divides at least one factor.
