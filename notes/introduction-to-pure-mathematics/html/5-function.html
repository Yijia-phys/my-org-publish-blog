Functions

Recall the definition of the Cartesian product: X×YX\times YX×Y consists of ordered pairs (x,y)(x,y)(x,y) with x∈Xx\in Xx∈X and y∈Yy\in Yy∈Y. A function selects exactly one output in YYY for each input in XXX.

Definition 1 — Function

Let XXX and YYY be sets. A function f:X→Yf:X\to Yf:X→Y is a subset f⊆X×Yf\subseteq X\times Yf⊆X×Y such that (∀x∈X)(∃!y∈Y) ((x,y)∈f). (\forall x\in X)(\exists!y\in Y)\,\bigl((x,y)\in f\bigr). (∀x∈X)(∃!y∈Y)((x,y)∈f). Thus every element of XXX occurs as the first entry of exactly one pair in fff. We write f(x)=yf(x)=yf(x)=y for this unique output, so f(x)=y  ⟺  (x,y)∈f. f(x)=y\iff(x,y)\in f. f(x)=y⟺(x,y)∈f. The set XXX is the domain and YYY is the codomain. The set of pairs fff is also called the graph of the function.

Both existence and uniqueness matter: an input cannot have no output, and it cannot have two different outputs. There is no requirement that every element of the codomain be used.

Corollary 2 — Equal inputs have equal outputs

Proof.

Injections and surjections

Definition 5 — Injective, surjective, and bijective functions

Let f:X→Yf:X\to Yf:X→Y be a function.

  1. The function is injective (or one-to-one) if equal outputs imply equal inputs: (∀x1,x2∈X) (f(x1)=f(x2)  ⟹  x1=x2). (\forall x_1,x_2\in X)\,\bigl(f(x_1)=f(x_2)\implies x_1=x_2\bigr). (∀x1​,x2​∈X)(f(x1​)=f(x2​)⟹x1​=x2​). Equivalently, by contraposition, distinct inputs have distinct outputs: (∀x1,x2∈X) (x1≠x2  ⟹  f(x1)≠f(x2)). (\forall x_1,x_2\in X)\,\bigl(x_1\ne x_2\implies f(x_1)\ne f(x_2)\bigr). (∀x1​,x2​∈X)(x1​=x2​⟹f(x1​)=f(x2​)).
  2. The function is surjective (or onto) if every element of the codomain is an output: (∀y∈Y)(∃x∈X) (f(x)=y). (\forall y\in Y)(\exists x\in X)\,(f(x)=y). (∀y∈Y)(∃x∈X)(f(x)=y). Equivalently, f[X]=Yf[X]=Yf[X]=Y.
  3. The function is bijective if it is both injective and surjective. Such a function is called a bijection or a one-to-one correspondence.

Remark 7 — Being a function is different from being injective

The definition of a function requires one output for each input. Injectivity requires at most one input for each output. Their implications point in opposite directions: x1=x2  ⟹  f(x1)=f(x2)for every function,f(x1)=f(x2)  ⟹  x1=x2for an injective function.\begin{aligned} x_1=x_2&\implies f(x_1)=f(x_2) &&\text{for every function},\\ f(x_1)=f(x_2)&\implies x_1=x_2 &&\text{for an injective function}. \end{aligned}x1​=x2​f(x1​)=f(x2​)​⟹f(x1​)=f(x2​)⟹x1​=x2​​​for every function,for an injective function.​ A function can send several inputs to the same output, as the absolute-value example shows. It is still a function; it simply fails to be injective.

Theorem 10 — A bijection reaches each target exactly once
