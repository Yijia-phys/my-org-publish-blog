Elements

We often want to consider several mathematical objects together. A set lets us treat such a collection as a single object and describe which objects belong to it.

Definition 1 — Sets and elements

A set is a collection of distinct objects, called its elements. If an object xxx belongs to a set AAA, we write x∈A, x\in A, x∈A, read "xxx is an element of AAA". If xxx does not belong to AAA, we write x∉A, x\notin A, x∈/A, which means ¬(x∈A)\neg(x\in A)¬(x∈A).

We can specify a finite set by listing its elements inside braces. The order of the list and any repetitions do not change the set.

Example 2 — Examples of sets and membership
  1. Let A={1,2,3}A=\{1,2,3\}A={1,2,3}. Then 2∈A2\in A2∈A and 4∉A4\notin A4∈/A. The lists {3,1,2}\{3,1,2\}{3,1,2} and {1,1,2,3}\{1,1,2,3\}{1,1,2,3} describe the same set AAA.
  2. The set of integers is Z={…,−2,−1,0,1,2,…}. \mathbb{Z}=\{\ldots,-2,-1,0,1,2,\ldots\}. Z={…,−2,−1,0,1,2,…}. We have −2∈Z-2\in\mathbb{Z}−2∈Z and 12∉Z\frac12\notin\mathbb{Z}21​∈/Z. Unlike the first example, this set has infinitely many elements.
Remark 3 — The empty set

The empty set, denoted by ∅\varnothing∅ or {}\{\}{}, is the set with no elements. For every object xxx, x∉∅. x\notin\varnothing. x∈/∅. Equivalently, there does not exist an object belonging to it: ¬(∃x (x∈∅)). \neg\bigl(\exists x\,(x\in\varnothing)\bigr). ¬(∃x(x∈∅)). The empty set has no elements, whereas {∅}\{\varnothing\}{∅} has one element: the empty set itself.

In this course, we treat numbers such as 333 as individual objects, rather than as sets. The expression {3}\{3\}{3}, however, denotes a set whose only element is 333. Thus 3∈{3}. 3\in\{3\}. 3∈{3}. The braces matter: 333 is a number, while {3}\{3\}{3} is a set containing that number. Being an element is a role an object plays in relation to a set; a set can itself be an element of another set, as ∅∈{∅}\varnothing\in\{\varnothing\}∅∈{∅} illustrates.

Definition 4 — Set-builder notation

Let AAA be a set, and let P(x)P(x)P(x) be a statement for each x∈Ax\in Ax∈A. The set-builder notation B={x∈A∣P(x)} B=\{x\in A\mid P(x)\} B={x∈A∣P(x)} denotes the set of all elements xxx of AAA for which P(x)P(x)P(x) is true. The vertical bar ∣\mid∣ is read "such that". In logical symbols, for every object xxx, x∈B  ⟺  (x∈A∧P(x)). x\in B\iff\bigl(x\in A\land P(x)\bigr). x∈B⟺(x∈A∧P(x)). Here the left side of the vertical bar specifies the candidate elements and the set they range over; the right side gives the condition those elements must satisfy.

Example 5 — Selecting integers by a condition

The set B={n∈Z∣0<n∧n<4}={1,2,3} B=\{n\in\mathbb{Z}\mid 0<n\land n<4\} =\{1,2,3\} B={n∈Z∣0<n∧n<4}={1,2,3} contains precisely the integers strictly between 000 and 444. For example, 2∈B2\in B2∈B, whereas 4∉B4\notin B4∈/B and 12∉B\frac12\notin B21​∈/B.

The condition is not itself an element of BBB: the elements are the numbers that satisfy it. Both parts matter; replacing Z\mathbb{Z}Z by R\mathbb{R}R would also admit numbers such as 12\frac1221​.

Relations between sets

Inclusion and equality

Definition 6 — Subsets and equality

Let AAA and BBB be sets.

  1. We say that AAA is a subset of BBB, written A⊆BA\subseteq BA⊆B, if every element of AAA belongs to BBB: A⊆B  ⟺  (∀x) (x∈A  ⟹  x∈B). A\subseteq B\iff(\forall x)\,(x\in A\implies x\in B). A⊆B⟺(∀x)(x∈A⟹x∈B).
  2. We write A⊈BA\nsubseteq BA⊈B when AAA is not a subset of BBB. This means that some element of AAA does not belong to BBB: A⊈B  ⟺  (∃x) (x∈A∧x∉B). A\nsubseteq B\iff(\exists x)\,(x\in A\land x\notin B). A⊈B⟺(∃x)(x∈A∧x∈/B).
  3. The sets AAA and BBB are equal, written A=BA=BA=B, if they have exactly the same elements: A=B  ⟺  (∀x) (x∈A  ⟺  x∈B). A=B\iff(\forall x)\,(x\in A\iff x\in B). A=B⟺(∀x)(x∈A⟺x∈B).
  4. We say that AAA is a proper subset of BBB, written A⊊BA\subsetneq BA⊊B, if A⊆BA\subseteq BA⊆B but A≠BA\ne BA=B. Equivalently, A⊊B  ⟺  (A⊆B∧(∃x) (x∈B∧x∉A)). A\subsetneq B\iff\bigl(A\subseteq B\land(\exists x)\,(x\in B\land x\notin A)\bigr). A⊊B⟺(A⊆B∧(∃x)(x∈B∧x∈/A)).

The symbols ∈\in∈ and ⊆\subseteq⊆ express different relations. For example, 3∈{3}3\in\{3\}3∈{3} says that 333 is an element, whereas {3}⊆{1,2,3}\{3\}\subseteq\{1,2,3\}{3}⊆{1,2,3} says that every element of one set belongs to another.

Theorem 7 — Basic properties of inclusion

Let AAA, BBB, and CCC be sets.

  1. Reflexivity: A⊆AA\subseteq AA⊆A.
  2. Transitivity: if A⊆BA\subseteq BA⊆B and B⊆CB\subseteq CB⊆C, then A⊆CA\subseteq CA⊆C.
  3. Equality by double inclusion: A=BA=BA=B if and only if A⊆BA\subseteq BA⊆B and B⊆AB\subseteq AB⊆A.
Proof.

Every element of AAA belongs to AAA, which proves reflexivity. For transitivity, let x∈Ax\in Ax∈A. Since A⊆BA\subseteq BA⊆B, we have x∈Bx\in Bx∈B, and since B⊆CB\subseteq CB⊆C, we then have x∈Cx\in Cx∈C.

If A=BA=BA=B, both inclusions hold. Conversely, if both inclusions hold, every element of either set belongs to the other, so the sets have exactly the same elements and are equal.

□
Corollary 8 — Inclusion and the empty set

For every set AAA, ∅⊆A,A⊆∅  ⟺  A=∅. \varnothing\subseteq A, \qquad A\subseteq\varnothing\iff A=\varnothing. ∅⊆A,A⊆∅⟺A=∅. In particular, ∅⊊A\varnothing\subsetneq A∅⊊A whenever AAA is nonempty.

Proof.

For every object xxx, the implication x∈∅  ⟹  x∈Ax\in\varnothing\implies x\in Ax∈∅⟹x∈A is true because its hypothesis is false. Thus ∅⊆A\varnothing\subseteq A∅⊆A. If also A⊆∅A\subseteq\varnothingA⊆∅, double inclusion gives A=∅A=\varnothingA=∅. The converse follows from reflexivity. The final assertion follows from the definition of a proper subset.

□

Definition 9 — Power set

The power set of a set AAA, denoted by P(A)\mathcal{P}(A)P(A), is the set of all subsets of AAA: P(A)={B∣B⊆A}. \mathcal{P}(A)=\{B\mid B\subseteq A\}. P(A)={B∣B⊆A}. Thus B∈P(A)  ⟺  B⊆A. Let AAA and BBB be sets.

  1. The union A∪BA\cup BA∪B consists of the objects belonging to at least one of AAA and BBB: A∪B={x∣x∈A∨x∈B},x∈A∪B  ⟺  (x∈A∨x∈B).\begin{aligned} A\cup B&=\{x\mid x\in A\lor x\in B\},\\ x\in A\cup B&\iff(x\in A\lor x\in B). \end{aligned}A∪Bx∈A∪B​={x∣x∈A∨x∈B},⟺(x∈A∨x∈B).​

Example 12 — Combining two finite sets

If A={1,2,3}A=\{1,2,3\}A={1,2,3} and B={3,4}B=\{3,4\}B={3,4}, then A∪B={1,2,3,4},A∩B={3}. A\cup B=\{1,2,3,4\},\qquad A\cap B=\{3\}. A∪B={1,2,3,4},A∩B={3}. The common element 333 appears only once in the union.

For complements, we first fix a set UUU containing all the elements under consideration, called the universal set. A complement always depends on this choice.

Theorem 15 — Laws of set operations

Let A,B,C⊆UA,B,C\subseteq UA,B,C⊆U, with all complements taken relative to UUU.

  1. Commutative laws: A∪B=B∪A,A∩B=B∩A.\begin{aligned} A\cup B&=B\cup A,\\ A\cap B&=B\cap A. \end{aligned}A∪BA∩B​=B∪A,=B∩A.​

Proof.

We prove the first distributive law. Unions and intersections of families

We can also combine more than two sets, including infinitely many. We first give a name to a collection whose members are themselves sets.

Definition 16 — Family of sets

A family of sets F\mathcal{F}F is a set whose elements are sets. A family of subsets of a set UUU satisfies F⊆P(U), \mathcal{F}\subseteq\mathcal{P}(U), F⊆P(U), or equivalently, (∀A∈F) (A⊆U). Translations and Cartesian products
